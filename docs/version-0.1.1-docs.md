# Version 0.1.1 Documentation

## Title
PHASE 02 / MILESTONE 2.1: OOP Abstraction Hierarchy Baseline

## Quick Diagnostic Read

`v0.1.1` introduces the first PHASE-02 implementation slice by adding the OOP hierarchy scaffold on top of the existing crypto engine.

This version is focused on interface and structure, not full behavior:

- `CryptoOperation` establishes encapsulated shared state and base contract shape.
- `TextCipher` and `FileCipher` establish inheritance, overload sets, and override sites.
- Encrypt/decrypt behavior in those concrete classes remains intentionally deferred to MILESTONE 2.2.

## One-Sentence Objective

Advance the project from crypto-engine-only APIs to a source-visible OOP hierarchy that satisfies the MILESTONE 2.1 concept-map contract and compiles cleanly in flat-directory mode.

## Scope and Versioning

- Previous documented version: `v0.1.0`
- Current documented version: `v0.1.1`
- Release type: pre-alpha patch milestone for PHASE-02 hierarchy scaffolding

## File-Level Change Summary

1. `aes256-java/CryptoOperation.java`

- Added abstract base class with:
  - private passphrase state (encapsulation boundary),
  - protected `AesGcmEngine` collaborator,
  - accessor/mutator methods,
  - final `banner()` template method,
  - abstract `describe()` for subclass specialization.

2. `aes256-java/TextCipher.java`

- Added concrete subclass extending `CryptoOperation`.
- Added overload signatures:
  - `encrypt(String plaintext)`
  - `encrypt(char[] plaintext)`
- Added `decrypt(String base64Envelope)` signature.
- Added override implementation for `describe()`.
- Behavior methods intentionally throw `UnsupportedOperationException` pending MILESTONE 2.2.

3. `aes256-java/FileCipher.java`

- Added concrete subclass extending `CryptoOperation`.
- Added overload signatures:
  - `encrypt(Path input)`
  - `encrypt(File input)`
  - `encrypt(Path input, Path output)`
- Added `decrypt(Path input)` signature.
- Added override implementation for `describe()`.
- Behavior methods intentionally throw `UnsupportedOperationException` pending MILESTONE 2.2.

4. `README.md`

- Bumped visible version marker to `v0.1.1`.
- Updated status, features, quick-start compile command, library-mode baseline notes, and roadmap milestone list.

5. `CHANGELOG.md`

- Added `v0.1.1` entry with scope, validation notes, and build-artifact deletion candidates.
